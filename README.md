# VSR Information Website

Health education platform providing information about Respiratory Syncytial Virus (VSR) for Argentine users.

## What it does

Educational website targeting adults over 60 and individuals with chronic diseases who face higher risk from VSR infections. Combines informational content with interactive vaccination center locating functionality.

## Features

- Five educational content pages covering VSR basics, risk factors, and prevention
- Interactive vaccination center map
- FAQ system with downloadable resources  
- User engagement tracking and feedback collection
- Mobile responsive design

## Installation (prod)

1. Deploy files to Apache web server
2. Configure analytics tracking IDs if needed

## Installation (dev)

1. Copy repo
2. Run `npx serve`
3. Open `http://localhost:3000/`

## Technology

- HTML5, CSS3, JavaScript (ES6+)
- Bootstrap framework
- Google Tag Manager + Adobe Analytics
- Interactive mapping libraries

## Target Audience

Primary: Adults 60+, individuals with chronic conditions
Secondary: Healthcare providers, family members seeking VSR information
